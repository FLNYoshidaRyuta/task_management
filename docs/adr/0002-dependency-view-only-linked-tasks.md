# ADR 0002: 依存関係図は依存の辺に参加するタスクだけを描く

- Status: Accepted
- Date: 2026-10-07

## Context

依存関係図は、全タスクをノードとして出力し、`depends_on` が解決できたものだけ矢印を引いていた。
依存のないタスクもノードとして並び、図の目的と合わない。

関連図は、解決できた `related` の辺に参加するタスクだけを描き、辺が無いときは空メッセージを出している。

## Decision

依存関係図は、解決できた `depends_on` の辺の両端だけをノードとして描く。
孤立ノードは出さない。
辺が1本も無いときは「依存関係はありません。」と表示する。

矢印の向きは従来どおり、依存先から依存元へ `dep --> target` とする。

解決できない `depends_on` は矢印を出さない。関連図と同様、不整合セクションは依存関係図には付けない。

## Consequences

依存を設定していないタスクは依存関係図に出ない。
作業順序の確認は依存関係図、期間はガントチャート、横断的な参照は関連図と役割が分かれる。
`depends_on` の正本は各タスクファイルのままであり、ビュー生成の変更だけで表現が変わる。
