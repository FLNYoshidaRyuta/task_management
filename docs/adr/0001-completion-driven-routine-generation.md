# ADR 0001: ルーティーンタスクを完了連動で生成する

- Status: Accepted
- Date: 2026-10-07

## Context

ルーティーンタスクは、今日から指定日数先までを一括生成していた。
この方式では未完了タスクがあっても次回以降が作られ、完了を契機に次の仕事を提示する要件と一致しない。
また、毎月第N曜日と日本の祝日を含む営業日補正を表現できない。

## Decision

対応周期を毎週指定曜日、毎月指定日、毎月第N指定曜日の3種類とする。
初回は休日補正後の期日が今日以降になる最初の1件だけを生成する。
以後は最新の親ルーティーンタスクが完了したときだけ、前回の論理期日から次回を1件生成する。

休日補正前の日付を `routine_date` として保持し、周期計算と重複判定に使う。
休日補正後の日付をタスクの `start` と `end` に使う。
日本の祝日は `jpholiday` で判定する。

毎月の指定日が存在しない場合は月末へ補正する。
第5指定曜日が存在しない場合は、その月の最終指定曜日へ補正する。

## Consequences

未完了タスクがある間は次回が表示されない。
完了反映後に生成スクリプトを実行する運用が必要になる。
周期計算は実行日や補正後期日ではなく、前回の論理期日を基準にするため日付がずれない。
日本の祝日判定のため、`jpholiday` が実行時依存になる。
旧定義の `daily`、`weekdays`、`generate_before_days` は使用できなくなる。
