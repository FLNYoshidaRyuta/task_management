## 概要

投稿の生成中は、投稿先ごとに進行が分かるようにする。生成が完了した本文は、その後に届く途中差分で上書きしない。ブラウザで契約違反を検出したときは、違反の種類と request_id を既存の監視へ送り、会話本文は送らない。

投稿下書きの表示状態（waiting / loading / partial / ready / failed）は残す。この状態の置き換えはしない。

## やったこと

- 複数の投稿先を生成しているとき、投稿先ごとに生成中、完了、失敗が分かる
- 完了した投稿先の本文は、後から届く途中差分で欠けた文章に戻らない
- 下書きの waiting / loading / partial / ready / failed は維持される
- 契約違反のとき、違反名、event 名、operation、`request_id`、`session_id` が監視に残る
- 会話本文、下書き本文、画像データは監視へ送らない
- 正常完了のときは、契約違反の報告を送らない

## 残りのやること

- 複数の投稿先を生成しているとき、投稿先ごとに生成中、完了、失敗が分かる
- 完了した投稿先の本文は、後から届く途中差分で欠けた文章に戻らない
- 下書きの waiting / loading / partial / ready / failed は維持される
- 契約違反のとき、違反名、event 名、operation、`request_id`、`session_id` が監視に残る
- 会話本文、下書き本文、画像データは監視へ送らない
- 正常完了のときは、契約違反の報告を送らない
