## やったこと

2026-10-27 のコメントで原因を整理した。口コミ画像のアップロード先と `mp2.SHOP_BBS.BBS_IMAGE` に保存する値が、旧 pro と新 pro で変わっている。

ログ確認では、本番サーバー内の `/pro_mypl_net/src/storage/app/public/` にファイルやディレクトリはなく、保存が失敗していると思われる。画面のエラーもエラーログも出力されない要因は次の3点: public ディスクの `throw` と `report` がどちらも `false`、`BbsService` が `false` を画像なしとして口コミ保存を続け `result_code: ok` を返す、画面は `ok` で成功トーストを出すため画像保存失敗をエラー表示しない。

影響範囲は 2026-08-31 10:39:32 以降の全 46 レコードで、対象店舗は再現検証を除き 6 店舗。詳細は GitHub issue コメント https://github.com/FutureLinkNetwork/mypl_pro/issues/337#issuecomment-6316786381
