## 概要

pro 側から画像付きで口コミを投稿しても、口コミ一覧で画像がプレビューされない。
再現手順は口コミ一覧から口コミを投稿（画像付き）すること。
期待する挙動は、一覧で画像がプレビュー表示されること。

## やったこと

- 口コミ画像のアップロード先と `mp2.SHOP_BBS.BBS_IMAGE` に保存する値が、旧 pro と新 pro で異なることを確認した。公開サイト（mypl_laravel3）からのアップロードは変わっておらず、保存先は S3 バケット `img-origin04.mypl.net`、`BBS_IMAGE` は `shopBBS/convert_{ハッシュ}.{拡張子}` のまま。
- 本番サーバー内の `/pro_mypl_net/src/storage/app/public/` にファイルやディレクトリがなく保存が失敗していると判断。画面・エラーログに出ない要因は、(1) public ディスクの `throw` / `report` がどちらも `false`、(2) `BbsService` が `false` を画像なしとして本体保存を続け `result_code: ok` を返す、(3) 画面が `ok` で成功トーストを出す、の 3 点。
- 2026-08-31 10:39:32 以降の全 46 レコードが画像を正常にアップロードできなかった可能性。対象店舗は再現検証を除き 6 店舗（Issue#337 コメントの集計）。
- 口コミ画像の保存先をローカルディスクから S3 アップロードへ修正したが、dev で PutObject が AccessDenied（バケット `img-origin04.mypl.net`、ロール `dev-mypl-app-laravel12-ec2-role`）。dev / 本番の IAM に `s3:PutObject` 付与を @fln-khirano に依頼。

## 残りのやること

- IAM 権限付与後、dev / 本番で S3 アップロードと口コミ一覧の画像表示を確認する。
- 必要に応じて本番への修正反映・リリースを行う。
