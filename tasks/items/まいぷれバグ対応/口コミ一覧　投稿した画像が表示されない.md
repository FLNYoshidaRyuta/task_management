## 概要

pro 側から画像付きで口コミを投稿すると、口コミ一覧で画像がプレビューされない。
再現手順は口コミ一覧から口コミを投稿（画像付き）すること。
期待する挙動は画像がプレビューできること。

## やったこと

dev 環境特有の挙動の可能性が指摘され、一旦 dev 特有と判断して close したが、再発のため reopen した。

口コミ画像のアップロード先と `mp2.SHOP_BBS.BBS_IMAGE` に保存する値が旧 pro と新 pro で異なることを調査した。公開サイト（mypl_laravel3）からのアップロードは変わっておらず、保存先は S3 バケット `img-origin04.mypl.net`、`BBS_IMAGE` は `shopBBS/convert_{ハッシュ}.{拡張子}` のまま。新 pro の一覧は `shopBBS/` で始まる値を CloudFront の URL にするため、公開サイト由来の画像は pro の一覧でも表示される。

| 項目 | 旧 pro | 新 pro |
| --- | --- | --- |
| アップロード先 | S3 バケット `img-origin04.mypl.net`（ACL public-read） | アプリの public ディスク（実体 `storage/app/public/bbs/{ショップID}/`） |
| `BBS_IMAGE` | `shopBBS/convert_{ハッシュ}.{拡張子}` | `bbs/{ショップID}/convert_{ハッシュ}.{拡張子}` |
| 一覧の画像 URL | `https://d3ct5lpp2cn35i.cloudfront.net/{BBS_IMAGE}?size=320x240&fit=contain` | `{APP_URL}/storage/{BBS_IMAGE}` |

新 pro で保存した `bbs/{ショップID}/...` は `/storage` 経由の URL となり、ブラウザから取得できないと一覧に画像が出ない。

公開サイトからアップロードされたと思われる投稿例: https://pro.mypl.net/bbs/304613（2026/10/02）。pro リニューアル以前の投稿例: https://pro.mypl.net/bbs/384674（2026/08/19）。

本番サーバー内の `/pro_mypl_net/src/storage/app/public/` にファイルやディレクトリはなく、保存が失敗していると思われる。画面のエラーもエラーログも出ないため未検出だった。要因は次の3点: public ディスクの `throw` と `report` がどちらも `false`（書き込み失敗は `false`、例外・ログなし）、`BbsService` が `false` を画像なしとして口コミ保存を続け `result_code: ok` を返す、画面は `ok` で成功トーストを出すため画像保存失敗をエラー表示しない。

2026-08-31 10:39:32 以降の全 46 レコードが画像を正常にアップロードできなかったと思われる。対象は 6 店舗（デモ店舗 1 件は再現テスト用で考慮不要）。影響件数: Manual Physio Salon AKIHA 4、柔揉み整体 松の実 1、カワウチケンチク 3、株式会社不動産の39 5、中京個別指導学院 長久手教室 23、ほっこりベビーマッサージ あっぷっぷ 9。

## 残りのやること

本番での画像保存失敗の解消と、口コミ一覧で新 pro 投稿画像がプレビュー表示されるよう不具合を修正する。
